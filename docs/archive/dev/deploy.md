📦 部署方案总览

  创建的文件结构

  deploy/
  ├── Dockerfile                    # 多阶段构建（4个目标）
  ├── docker-compose.yml            # 开发环境（6服务）
  ├── docker-compose.prod.yml       # 生产环境（15+服务）
  ├── docker-compose.full.yml       # 企业环境（30+服务）
  ├── Makefile                      # 快捷命令
  ├── .env.example                  # 环境变量模板
  ├── QUICKSTART.md               # 5分钟快速开始
  ├── README.md                   # 完整部署文档
  ├── DEPLOYMENT_SUMMARY.md       # 方案总结
  ├── scripts/
  │   ├── deploy.sh               # 智能部署脚本
  │   ├── health-check.sh         # 健康检查
  │   └── init-db.sql             # 数据库初始化
  └── config/
      ├── prometheus.yml          # 监控配置
      ├── nginx/nginx.conf        # 负载均衡
      └── grafana/datasources/    # 监控面板

  ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
  🚀 快速开始

  # 启动开发环境
  make dev

  # 健康检查
  ./deploy/scripts/health-check.sh

  # 查看状态
  make status

  访问服务:

  • API: http://localhost:8080
  • Grafana: http://localhost:3000 (admin/admin)
  • Prometheus: http://localhost:9091
